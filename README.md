# 🌤 三城天气查询应用

一个简洁美观的天气查询 Web 应用，支持在 **青岛李沧 · 烟台芝罘 · 威海文登** 三个城市间自由切换，查看实时天气信息。

## 功能

- ✅ 三城一键切换（青岛李沧、烟台芝罘、威海文登）
- ✅ 实时温度、体感温度显示
- ✅ 湿度、风力风向、能见度、气压
- ✅ 天气图标 + 中文描述
- ✅ 智能穿衣建议（9 档温度区间）
- ✅ 天气自适应背景（晴朗/阴天/雨雪）
- ✅ 响应式设计（手机/电脑均可）
- ✅ API Key 本地存储，一次配置长期使用

## 在线预览

直接打开 `weather.html` 即可使用。

## 使用方式

1. 打开 `weather.html`
2. 注册 [OpenWeatherMap](https://openweathermap.org/api) 免费账号，获取 API Key
3. 将 API Key 粘贴到页面顶部输入框，点击「保存」
4. 点击城市标签切换查看天气

## 技术栈

- 纯 HTML + CSS + JavaScript（零外部依赖）
- 数据来源：OpenWeatherMap API
- 天气自适应渐变背景
- 毛玻璃效果卡片设计
